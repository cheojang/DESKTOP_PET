# 모션 교리 — 루핑 애니메이션 제작 원칙

> 출처: 사용자 제공 레퍼런스 (Seedance 2.0 "이미지를 영상으로" 프롬프트 문법, 2026-07-14).
> 원문 핵심: *"애니메이션은 끝과 시작 모션이 동일해서 루핑되어야 함. 카메라 이동 및
> 줌인·줌아웃 금지. 동물(주체)만 움직임."*
>
> 데스크톱 펫은 AI 영상이 아니라 **이산 스프라이트 프레임**을 쓰지만, 루핑 모션의
> 원칙은 매체와 무관하게 동일하게 적용한다. 앞으로 모든 상태 모션(신규 포함)은
> 이 교리를 만족해야 한다.

## 5대 원칙

### 1. 끝 = 시작 (Seamless Loop)
사이클의 마지막 프레임 → 첫 프레임 전환이, 내부 프레임 전환과 **동일하게 매끄러워야**
한다. 스프라이트 사이클은 순환(cyclic)이므로 `lastN → frame0` 이음새를 항상 검사한다.
- **idle**: `idle0 ↔ idle1` 핑퐁(호흡). A→B→A→B… 자동 루프.
- **walk**: `contact → passing → contact' → passing' → (첫 contact)`. 대칭 4프레임.
  passing 두 장(walk1, walk3=mirror)이 접점이 되어 어느 방향으로 감아도 이음새가 없다.
- **drag/fall**: 2프레임 교대(흔들림/허우적). 대칭이라 자동 루프.
- **금지**: "재생 후 처음으로 툭 튀는" 이음새. GIF로 뽑아 튐이 보이면 실패.

### 2. 카메라 고정 (No Global Transform)
프레임 간 **캔버스 크기·스케일·캐릭터 위치는 불변**. 줌·팬 금지.
- 화면상의 이동(걷기로 x가 변함)은 **상태머신(`self.x`)이 담당**하고, 스프라이트 프레임은
  제자리(80×120 고정)에서 팔다리만 움직인다. 렌더러는 프레임을 그대로 얹을 뿐 확대/이동 안 함.
- 프레임 자체에 전역 이동·확대를 넣지 말 것(그건 "카메라 줌"에 해당).

### 3. 접지 안정 (Planted Baseline)
바닥에 닿은 발의 y좌표는 사이클 내내 **고정**(바운스 ±1px만 허용).
- 접지발이 프레임마다 튀면(teleport) 미끄러지거나 순간이동하는 것처럼 보여 루프가 깨진다.
- 바운스는 **몸통·머리를 올려서** 표현하고(passing에서 상승), 접지발은 붙여 둔다.
- 기준선: 바닥 y≈114~115, 중심 x=40. 신규 포즈도 이 접지선을 지킨다.

### 4. 주체만 움직임 (Subject-Only)
배경 투명, 캐릭터 드리프트 없음. 움직임은 **의미 있는 부위에 국한**:
팔·다리 스윙, 몸통 바운스, 귀·프릴의 미세 흔들림. 장식이 제멋대로 떠다니지 않게.

### 5. 의미 있는 모션 (Semantic Motion)
모션이 **캐릭터의 상태·정체성을 반영**해야 한다.
- walk = 이동 의지(교대 보행), sleep = 이완·호흡(웅크림+Zzz),
  drag = 매달려 흔들림(팔 위로·몸 늘어짐), fall = 통제 불능 허우적(팔다리 벌림).
- 상태를 몰라도 실루엣 모션만으로 무엇을 하는지 읽혀야 한다.

## 제작 절차 (신규/수정 모션)
1. 사이클 프레임 수 결정: idle 2 / walk 4 / drag·fall·sleep 2. (필요 시 늘림)
2. **사이클 상수 고정**: 접지발 y, 중심 x, 개구부(FACE_ANCHOR) 크기.
3. 프레임별로 "무엇이 얼마나 움직이는가"만 델타로 기술(원칙 4).
4. **이음새 검사**: `python render_loops.py`(루트)로 상태별 루프 GIF를 뽑아 육안 확인.
   발 튐·몸 드리프트·역재생 느낌이 있으면 프레임 수정.
5. **재생 속도 검증**: 렌더러의 실제 프레임 스텝으로 확인.
   - walk: `step = max(1, 8 / walk_speed)` 틱마다 다음 프레임 → CPU 사용률(walk_speed)에 비례해 빨라짐.
   - idle //24, sleep 포즈 //36 · Zzz //30, drag/fall //8.

## 안티패턴 (하지 말 것)
- 프레임 안에서 캐릭터를 통째로 확대/이동(줌·팬) → 원칙 2 위반.
- contact 프레임에서 두 발을 동시에 크게 벌려 다음 프레임과 x가 튐 → 원칙 3 위반.
- 마지막 프레임을 첫 프레임과 무관하게 그려 루프 이음새가 끊김 → 원칙 1 위반.
- 걷기에서 다리가 중심선을 넘어 교차(v1 실패 사례) → 미끄러지듯 어색.
